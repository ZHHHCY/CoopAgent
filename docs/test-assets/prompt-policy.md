# 测试题面约定

`community-designs.csv` 的 `prompt_draft` 是发送给 Agent 的用户需求，只描述要做什么：目标指挥官、单位或技能、数值变化，以及必要的等级、研究或威望条件。

不为普通题面附加“不要改其他内容”“保留原有效果”等保护性清单。保留原行为是产品默认要求，未改项放在独立验收侧，且必须以真实数据为依据，不能事先假定某升级与生产或研究无关。

来源摘要、待确认问题和验收备注不拼入 Agent 输入。历史运行报告与表格快照保留当时输入，不回写成新结果。新一轮测试保存实际发送的题面，方便比较。

2026-09-10 清理了 31 条题面的附加约束。本轮数值复测范围为 COMM-029 至 COMM-044；COMM-044 按“10 级时序能力的原有加成从 50% 改为 25%”验收，移除旧备注中对生产、研究影响的预设。
